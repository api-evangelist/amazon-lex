Web Search on Amazon Bedrock AgentCore is now generally available, providing a managed web search tool that grounds AI agents in current information and addresses knowledge cutoff limitations. It operates through a purpose-built Amazon web index spanning billions of documents refreshed within minutes, with semantic snippet extraction, a knowledge graph for factual accuracy, and privacy-by-design keeping queries within AWS infrastructure. It integrates via MCP and is priced at $7 per 1,000 queries.
